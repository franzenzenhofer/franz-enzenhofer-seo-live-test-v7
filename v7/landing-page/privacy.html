Privacy Policy

Last updated: January 2026

Overview

SEO Live Test is a browser extension that analyzes web pages for SEO issues. This policy explains how we handle your data.

Data Collection

We take your privacy seriously:

  • We do NOT collect any personal information
  • We do NOT track your browsing history
  • We do NOT send your data to external servers
  • All SEO analysis runs entirely in your browser

Google API Access

If you choose to connect Google Search Console or Analytics (optional):

  • We request read-only access to your data
  • Data is fetched directly from Google to your browser
  • We do not store, transmit, or share this data
  • You can disconnect at any time in extension settings

Local Storage

The extension stores the following data locally in your browser:

  • Your preferences (enabled rules, display settings)
  • Cached analysis results for the current session
  • Run history (if enabled)

This data stays in your browser and is never transmitted.

Permissions Explained

  • sidePanel: Display results in Chrome's side panel
  • tabs: Detect navigation to trigger analysis
  • scripting: Inject content scripts for DOM analysis
  • storage: Save preferences locally
  • webRequest: Analyze HTTP response headers
  • webNavigation: Track navigation for analysis timing
  • identity: Optional Google account OAuth
  • alarms: Schedule background cleanup tasks
  • contextMenus: Right-click menu options
  • host_permissions: Analyze any webpage you visit

Third-Party Services

Optional integrations (require explicit consent):

  • Google Search Console API: Fetch search performance data
  • Google PageSpeed Insights API: Fetch performance scores

No data is shared with any other third parties.

Data Security

All data stays in your browser, protected by Chrome's built-in security. Clearing browser data removes all extension data.

Changes to This Policy

Updates will be posted on this page with a revised date.
